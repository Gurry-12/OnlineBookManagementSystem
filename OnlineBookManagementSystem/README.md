# Whispering Pages - Online Book Management System

![Project Header](/Presentation/wwwroot/images/demo-book-placeholder.svg)

A premium, modern Book Management System built with .NET 9 and Clean Architecture.

## 🚀 Vision
To provide a seamless, interactive, and visually stunning platform for book lovers to explore, manage, and purchase their favorite titles.

## ✨ Features
- **Clean Architecture:** Domain-driven design with separate layers for Core, Infrastructure, and Presentation.
- **Role-Based Access:** Specialized dashboards for Public Users, Registered Users, Admins, and Super Admins.
- **Glassmorphic UI:** A state-of-the-art frontend design system using CSS glassmorphism, smooth animations, and responsive layouts.
- **Real-time Analytics:** Super Admin dashboard with sales charts, user activity logs, and system metrics.
- **Comprehensive Catalog:** Categorized books with advanced search, favorites, and review systems.

## 🛠️ Technical Stack
- **Backend:** .NET 9, ASP.NET Core MVC, Entity Framework Core
- **Database:** SQLite (Relational)
- **Frontend:** Vanilla CSS (Modern CSS3), JavaScript (ES6+), Bootstrap 5 (Base Grid)
- **Identity:** ASP.NET Core Identity with role-based authorization

## 🏗️ Getting Started
1. Clone the repository.
2. Run `dotnet ef database update`.
3. Run `dotnet run`.
4. Login with seeded credentials (check `appsettings.json` for defaults).
